# セクション比較・A/Bワークスペース

原詞と訳詞を独立した歌詞A/Bとして編集し、セクションや行を対応させて比較できます。

## 原詞と訳詞を編集する

1. 歌詞Aへ原詞を入力するか、上部の「開く」から取り込みます。
2. 「A/B比較」を押すと、空の歌詞Bと左右分割が開きます。Bへ訳詞を入力するか、Bを選択してファイルを開きます。空のBには「AをBへ複製して始める」も表示します。
3. 必要なら「上下に分割」へ変更し、境界をドラッグして調整します。境界へTabで移動した場合は矢印キー、Home / Endでも調整できます。
4. 下部の比較対象を、それぞれの文書全体またはセクションへ設定します。比較表の本文を押すと、該当するエディターの選択範囲へ移動します。

A/Bは別の文書・編集履歴です。右の読み設定、左の楽曲構成、タイトル、通常の保存・テキスト書き出しは操作中の歌詞に追従します。`Alt+1` / `Alt+2` で入力先も切り替わります。単一表示へ戻しても、隠れた歌詞とUndo履歴は保持します。アプリ再起動では本文・設定を復元し、Undo履歴そのものは復元しません。

「セクション比較」は操作中の1文書を左右の比較元にします。比較欄のA/Bはこの場合、比較する左・右の対象を示します。各セレクターでVerse 1とVerse 2などを選びます。

## 対応行と数値

- 初期対応は本文の行順です。空行・タグだけの行・未閉鎖タグの保留部分は本文の比較対象から除外します。
- 各行の選択欄で対応先を交換できます。「空きを入れる」「空きを詰める」で、訳詞の行数が異なる場合も調整できます。原文は書き換えません。
- 行がない側は「対応する行なし」とし、ゼロ音として差を計算しません。
- 差は **B − A**。日本語モーラと英語シラブルは別々の値です。日本語6モーラと英語4シラブルを「2音差」とは扱いません。
- 読み未確定・辞書外語・暫定のセクション所属を含む差には `*` を付け、確定部分だけの差であると示します。
- 1つの物理行が複数セクションにまたがる場合、その行単位の音数差は `—` とします。セクション合計は解析範囲に基づいて表示します。

手動対応は、その時点の本文行と比較対象のスナップショットへ結び付けて保存します。本文が変わると以前の対応を適用せず、現在の行順を仮表示して再確認を求めます。読みだけの変更なら対応は保持します。現在は意味による自動対応や、本文編集後の手動対応の自動追従は行いません。

## 保存とデータ保全

| 操作 | 保存する内容 |
|---|---|
| 自動保存 | A/B、選択ペイン、分割方向・比率、比較対象、手動対応 |
| 保存 / Ctrl+S | 操作中の1文書の `.lyrics.json` |
| A/Bをまとめて保存 / Ctrl+Shift+S | `.lyrics-workspace.json`。上部の「開く」から復元 |
| テキスト書き出し | 操作中の1文書の原文・タグ。読みは含まない |

自動保存はIndexedDBの1レコードへまとめて書き込み、片方だけが新しい状態にならないようにしています。従来の単独文書の保存キーは変更せず、新形式がない場合だけ読み込んで移行します。不正・未来版のワークスペースがあれば、その保存内容を保持して起動を止めます。

ファイルを開く前に現在のワークスペースを退避します。その処理中に追加入力があった場合は差し替えを中止し、入力を保持します。変換中の置換も保留します。退避コピーを選んで戻す履歴UIはまだありません。

同じoriginの編集はWeb Locksで1タブに制限します。2つ目は編集・自動保存を開始せず、先のタブを閉じてロックを取得してから最新内容を読み込みます。独立した複数プロジェクトの同時編集は今後の対象です。
